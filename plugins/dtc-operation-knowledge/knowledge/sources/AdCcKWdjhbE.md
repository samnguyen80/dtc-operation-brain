# Use Returns Data to Improve Ecommerce

- **Watch:** https://youtu.be/AdCcKWdjhbE
- **Date:** 2022-04-25 · 4:22
- **Channel:** ReturnLogic

**Thesis:** Returns data is an operating dataset that can expose defects, expectation gaps, fulfillment bottlenecks, and customer patterns—but only if reasons and dispositions become decisions outside the returns team.

## Transcript-grounded takeaways

- Return reasons can identify where product descriptions, photography, sizing, or UX fail to communicate what the customer will receive (0:00–2:04).
- Fulfillment-time patterns in return data can reveal staffing, resource, or operating-hour problems, connecting reverse logistics to outbound operations (1:01–2:04).
- Customer return behavior can be joined with recency, frequency, and monetary value to distinguish patterns and personalize follow-up instead of treating every return identically (2:04–3:04).
- The point of analytics is action: update the page, product, process, or customer treatment that caused the return rather than merely reporting a lower or higher rate (0:00–3:04).
- The video says offering warranties as a return type reduced refund rate by **10%** across its dataset **[claimed]**; category, method, and denominator are not provided (3:04–4:05).
- A cited customer case reportedly reduced multi-size purchases by **15%** **[claimed]**; the transcript does not provide the intervention design or independent verification (3:04–4:05).
